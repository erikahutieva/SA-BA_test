@startuml
autonumber

actor "Клиент" as C
participant "Сайт" as W
participant "Система бронирования" as P
participant "Система заказов (OMS)" as OMS
participant "Платёжная система" as PG
participant "Поставщик" as S
participant "Наземная служба" as G
actor "Бортпроводник" as F

== Заказ и оплата ==
C -> W: Номер бронирования, фамилия
W -> P: Запрос бронирования
P --> W: Рейс, пассажир, место, статус
W -> OMS: Запрос меню по рейсу
OMS --> W: Меню, цены, остатки
C -> W: Выбор позиций
W -> OMS: Создание заказа
OMS -> OMS: Проверка cut-off (>= 24 ч),\nрезерв, статус CREATED
OMS --> W: order_id, сумма, срок действия
C -> W: Оплатить
W -> OMS: Запрос оплаты order_id
OMS -> OMS: Проверка cut-off, PAYMENT_PENDING
OMS -> PG: Платёж: order_id, сумма,\nidempotency_key
PG --> OMS: Callback: ID платежа, статус

alt Оплата успешна
    OMS -> OMS: PAID
    OMS --> W: Подтверждение заказа
    W --> C: Заказ оформлен
else Ошибка оплаты
    OMS -> OMS: PAYMENT_FAILED
    W --> C: Ошибка, можно повторить\n(до cut-off)
end

== Cut-off (за 24 ч до вылета) ==
OMS -> OMS: Закрытие продаж,\nнеоплаченные -> EXPIRED, снятие резервов
OMS -> S: Заявка по рейсу (SENT_TO_SUPPLIER):\nрейс, вылет, аэропорт, заказы,\nместа, состав, количество, доставка
S --> OMS: Подтверждение / отказ по позициям

== Доставка и загрузка ==
S -> G: Питание в аэропорт
G -> OMS: Приёмка: факт. время, кол-во (DELIVERED)
G -> F: Передача на борт
G -> OMS: Подтверждение загрузки (ON_BOARD)
OMS -> F: Список заказов рейса\n(загрузка на устройство до вылета)

== Выдача ==
F -> C: Выдача питания
F -> F: Фиксация результата (offline)
F -> OMS: Пакет результатов после посадки:\norder_id, результат, время, причина

alt Выдано
    OMS -> OMS: ISSUED -> COMPLETED
else Не выдано
    OMS -> OMS: NOT_ISSUED -> REFUND_PENDING
end

== Возвраты и отказы (общий блок) ==
note over OMS, PG
Возврат -> REFUNDED
запускается при:
- отмене клиентом до cut-off
- отказе поставщика без замены
- недопоставке (DELIVERY_FAILED)
- отмене/переносе рейса (BRON -> OMS)
- невыдаче по вине авиакомпании
Клиент уведомляется по email/SMS/push.
end note

OMS -> OMS: Реестр выполненных заказов\nдля бухгалтерии и расчётов с поставщиком
@enduml
