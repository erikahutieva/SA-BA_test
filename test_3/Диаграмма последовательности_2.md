@startuml

autonumber

actor "Бортпроводник" as FA
participant "Система расписания\nи экипажей" as Crew
participant "Система питания" as Meal
participant "Система расчёта\nкомпенсаций" as Comp
participant "Подрядчик" as Contractor

Crew -> Comp: Передать данные смены и маршрута

Comp -> Comp: Определить аэропорт\nначала смены

alt Смена начинается во Внуково

    Comp -> Meal: Создать задание\nна самостоятельное получение

    Meal -> FA: Уведомить о необходимости\nполучить питание
    FA -> Meal: Получить питание
    Meal -> Comp: Подтвердить получение

else Внуково — промежуточный аэропорт

    Comp -> Comp: Определить время стоянки

    alt Стоянка >= 3 часов

        Comp -> Meal: Создать задание\nна самостоятельное получение
        Meal -> FA: Уведомить о получении питания
        FA -> Meal: Получить питание
        Meal -> Comp: Подтвердить получение

    else Стоянка < 3 часов

        Comp -> Contractor: Передать задание на доставку
        Contractor -> Meal: Получить питание
        Contractor -> FA: Доставить питание на борт
        Meal -> Comp: Подтвердить доставку

    end

end

alt Питание получено бортпроводником

    Comp -> Crew: Получить фактические времена рейса
    Crew --> Comp: Вылет из Внуково /\nвремя окончания полёта

    Comp -> Comp: Определить количество часов\nпосле вылета из Внуково
    Comp -> Comp: Рассчитать компенсацию

    Comp -> Comp: Создать начисление

else Питание доставлено подрядчиком

    Comp -> Comp: Компенсация\nне начисляется

end

@enduml
